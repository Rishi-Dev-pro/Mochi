# Mochi Client (Frontend)

React + Vite + Three.js frontend for the Mochi AI Companion.

## Setup
```bash
npm install
```

## Development
```bash
npm run dev
```

Runs on `http://localhost:5173`

## Build
```bash
npm run build
npm run preview
```

## Test
```bash
npm run test
npm run test:ui
```

## Code Quality
```bash
npm run lint
npm run format
```
