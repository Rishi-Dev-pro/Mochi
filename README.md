# Mochi AI Companion

Persistent 3D AI companion with emotional memory and unprompted check-ins.

## Quick Start

### Prerequisites
- Node.js 18+ (check: `node -v`)
- npm 9+ (check: `npm -v`)

### Setup
```bash
# Install frontend
cd client && npm install

# Install backend
cd ../backend && npm install
```

### Run Locally
```bash
# Terminal 1: Frontend (http://localhost:5173)
cd client && npm run dev

# Terminal 2: Backend (http://localhost:3001)
cd backend && npm run dev
```
